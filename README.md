## Getting started

Prerequisites
- Python 3.8+ (3.10+ recommended)
- pip
- (Optional) virtualenv or venv

Quick setup
1. Clone the repository:
   git clone https://github.com/mofokengpablo0/Pablo_Projects.git
2. Change into the repo:
   cd Pablo_Projects
3. Create and activate a virtual environment:
   - macOS / Linux:
     python -m venv venv
     source venv/bin/activate
   - Windows (PowerShell):
     python -m venv venv
     .\venv\Scripts\Activate.ps1
4. Install dependencies (if a requirements file exists):
   pip install -r requirements.txt

If there's no requirements.txt, check individual project folders for dependency instructions.
